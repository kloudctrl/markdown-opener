Markdown Opener — Privacy Policy
Last updated: October 8, 2026

Markdown Opener does not collect, store, transmit, sell or share any personal data.

What the extension accesses
• The text of Markdown documents you open, only to display them. Processing happens entirely in your browser.
• Markdown URLs you ask it to load in its viewer. These are fetched directly from that website by your browser. If you grant a site permission, your browser's existing cookies for that site are sent so that files you can already access load correctly.

What the extension stores
• Your display preferences (theme, width, font size, and on/off options), saved with Chrome's built-in storage and synced by Chrome to your Google account if Chrome sync is enabled. The developer has no access to this data.

No analytics, tracking, advertising, or third-party services are used.
